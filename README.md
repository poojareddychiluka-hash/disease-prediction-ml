# Disease Prediction using Machine Learning

## Project Overview
This project predicts the possibility of heart disease using Machine Learning classification algorithms. The model is trained using patient medical data and compares multiple classification techniques to identify the best-performing model.

## Dataset
- Dataset: Heart Disease Dataset
- Total Patients: 303
- Features: 13
- Target: Presence or absence of heart disease

## Machine Learning Algorithms
The following algorithms were implemented:
- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest
- XGBoost

## Model Performance

| Model | Accuracy |
|---|---:|
| Logistic Regression | 86.89% |
| SVM | 85.25% |
| Random Forest | 88.52% |
| XGBoost | 88.52% |

## Best Model
Random Forest achieved the best performance with an accuracy of **88.52%**.

## Project Workflow
1. Load the dataset
2. Explore and preprocess the data
3. Split the data into training and testing sets
4. Train different Machine Learning models
5. Evaluate model performance
6. Compare the models
7. Select the best-performing model

## Conclusion
The project demonstrates how Machine Learning classification algorithms can be used to predict the possibility of heart disease from medical data. Among the tested models, Random Forest and XGBoost achieved the highest accuracy of 88.52%.
